# Side B 1.2.0 — macOS & Windows Feature Parity

This feature-parity beta brings the Windows client in line with the core macOS experience: music discovery, library and playlist management, playback, lyrics, and Genius song information. The macOS download also includes the Genius, queue and updater follow-up fixes listed below. Package build information identifies each platform's source revision.

## Highlights

- Personalized Home with Speed Dial, featured albums and playlists, configurable recommendation sources, and local-time greetings.
- Explore, search, collection filters, library, history, and playlist actions across both platforms.
- Fullscreen playback with queue controls, artist and album links, lyrics, Genius annotations, and song information.
- Native Windows playback and media controls, persistent preferences, and English/Spanish interface support.

## Fixes and improvements

- Speed Dial tracks now resolve the actual album name instead of showing view counts, while preserving the album link and ongoing playback.
- Home now shows a larger greeting without the redundant subtitle; greetings update automatically according to local time.
- Improved Genius text wrapping, annotation anchoring and outside-click dismissal, and information-card sizing on large screens.
- Refined queue-button order, spacing, drag-handle alignment, and fullscreen Like/Information buttons.
- Aligned collection search and filter controls with playback actions, removed redundant navigation/menu controls, and fixed album colors in the title bar.
- Improved fullscreen artwork colors, metadata typography, and the rounded Windows application icon, including the icon embedded in the executable.
- Genius annotations offer artwork, contrast and neutral colors on both platforms, with English/Spanish labels on macOS. Optional exponential volume remains Windows-specific.
- macOS queue duration and drag handle share the same alignment. Like stays available across queue rows, and resolved track duration survives skipping, going back and restoring a session.
- The macOS updater selects the macOS package explicitly when Windows downloads are present in the same release.

## Downloads

- **macOS:** `SideB-macOS.zip` — Apple Silicon, macOS 15 or later. Ad-hoc signed; not Developer ID notarized.
- **Windows:** `SideB-Windows-x64-setup.exe` — installer for 64-bit Windows with WebView2.
- **Windows portable:** `SideB-windows-x64.zip` — executable, libmpv, Vulkan runtime, and license; extract the whole archive before launching.
- SHA-256 checksum files are included for both platforms.

These downloads remain version 1.2.0 (build 13). Download the refreshed macOS ZIP directly to install the latest Mac fixes. If the updater offers 1.2.0 again after installation, choose Skip this version; beta-tag comparison will be corrected in a follow-up.

Side B is still in beta, as were the earlier releases. Version 1.2.0 does not mark a stable release. Build/test results do not replace testing playback, account flows, or platform-specific UI on real devices. Report issues with your operating system and reproduction steps.
